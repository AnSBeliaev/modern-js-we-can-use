# Можно ли это использовать?

- **На caniuse.com мы видим процент — это доля людей в мире, чей браузер уже понимает конкретную возможность JavaScript.** У метода `toSorted` на сайте одна цифра, у `Object.groupBy` — другая.
- **Сборка берёт файлы проекта и отдаёт браузеру уже другой JavaScript.** Какой именно, решают две настройки: список браузеров в `.browserslistrc` и `target` в `tsconfig` — до какой версии языка переписывать синтаксис.
- **С кодом при этом происходит одно из двух.** Новый синтаксис сборка переписывает в старый. Для нового метода, которого нет у браузера из списка, добавляет полифил: готовую реализацию этого метода.

# Полифил скачивают все

- **Сборка читает `.browserslistrc` до открытия сайта.** Если метода нет у браузера из списка, готовая реализация попадает в отдельный файл.
- **Этот файл скачивают все.** В том числе те, чей браузер метод уже знает.

| Что скачивает посетитель | gzip |
| --- | --- |
| Код приложения | 68,78 КБ |
| Файл полифилов, `toSorted` в коде ещё нет | 11,94 КБ |
| Тот же файл, в коде вызван `toSorted` | 12,09 КБ |

`toSorted` добавляет 0,15 КБ. Сам вызов сборка не переписывает, он остаётся в коде приложения.
